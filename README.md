# bangla-books-scraper
## Project Description
This project scrapes book information from books.com.bd using Python.

## Technologies Used
- Python
- Requests
- BeautifulSoup
- Pandas

## Source Website
http://books.com.bd/list/

## Dataset
The scraped book data is saved in CSV format.

## Files
- `openlibrary_scraper.py` — Web scraping code
- `bangla_books_dataset.csv` — Scraped dataset
